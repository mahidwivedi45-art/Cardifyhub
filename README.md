# 💍 NCR Wedding Vendors

A premium wedding vendor discovery marketplace for Delhi NCR.

## 🌟 About

NCR Wedding Vendors is a digital marketplace designed to help
couples discover wedding vendors in Delhi NCR.

Customers can explore vendors, view their profiles and portfolios,
and contact them directly.

Vendors can create their own business listings and submit them
for approval.

## 🔐 Firebase

Firebase will be used for:

- Firebase Authentication
- Cloud Firestore
- Firebase Storage
- Firebase Security Rules

Firebase Authentication will handle customer and vendor accounts.

Cloud Firestore will store:

- Users
- Vendors
- Categories
- Locations
- Enquiries
- Reviews
- Admin data

Firebase Storage will be used for vendor portfolio images.
