# CardifyHub

Next.js SaaS starter for ecommerce real-profit analytics.

Included: premium landing page, CSS 3D-style motion, dashboard demo, Firebase-ready auth, Shopify/WooCommerce API route structure, profit engine, Free/Growth/Scale pricing, Cashfree billing route placeholders, AI route, SEO files and legal page placeholders.

## Run
npm install
npm run dev

Copy `.env.example` to `.env.local`. Never commit `.env.local` or server secrets.

## Important
The project is intentionally a safe starter. Real Shopify OAuth token exchange/HMAC verification, WooCommerce credential encryption, Firebase Admin sessions, Cashfree signature verification/webhooks and production AI provider calls must be configured before accepting real customer data or money.
